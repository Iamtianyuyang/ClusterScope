101:本集群实测走的就是这条:源码编译到 `~/pg16`,数据目录 `~/pgdata`,用普通账号起停。
105:./configure --prefix="$HOME/pg16" && make -j"$(nproc)" && make install
108:"$HOME/pg16/bin/initdb" -D "$HOME/pgdata" -U clusterscope --auth=trust
111:"$HOME/pg16/bin/pg_ctl" -D "$HOME/pgdata" -l "$HOME/pgdata/server.log" -o "-p 5432 -k /tmp" start
112:"$HOME/pg16/bin/createdb" -h 127.0.0.1 -p 5432 -U clusterscope clusterscope
115:"$HOME/pg16/bin/pg_ctl" -D "$HOME/pgdata" stop
118:`postgres_url` 填 `postgresql://clusterscope:<口令>@127.0.0.1:5432/clusterscope`;
119:`initdb` / `pg_ctl` / `psql` 不在 PATH 时用 `$HOME/pg16/bin/` 下的完整路径。
