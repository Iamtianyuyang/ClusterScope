    fix: unbreak audit-log listing, unblock scheduler head-of-line, guard duration narrowing
    
    - audit_logs always returned 500: AuditLogRow mapped the 'username'
      column to a 'user' field (sqlx ColumnNotFound at runtime), and the
      COUNT query never bound the filter parameters. Rename the field and
      bind the same values in both count and page queries.
    - Scheduler loaded only the 100 oldest queued jobs per cycle; when those
      could not run (e.g. all pinned to a busy node) newer jobs never
      entered the in-memory queue even with idle capacity elsewhere. Load
      all queued jobs (the queue dedups on job_id).
    - create_alert_rule narrowed duration_seconds i64 -> i32 with ,
      truncating oversized values to 0 (instant-firing rules); range-check
      with try_from instead.
