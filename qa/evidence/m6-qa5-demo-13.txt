# 核心判据：任何筛选条件都要让 total 等于实回条数（F-16 的 COUNT 语句必须绑上自己的参数），并与 psql 的计数对齐
$ sh qa/harness/m6-demo-audit.sh
admin 登录: token len=268
GET /api/audit-logs?page_size=500
    -> {"total":354,"rows":354}
GET /api/audit-logs?page_size=500&user=admin
    -> {"total":130,"rows":130}
GET /api/audit-logs?page_size=500&action=login
    -> {"total":215,"rows":215}
GET /api/audit-logs?page_size=500&start_time_ms=0
    -> {"total":354,"rows":354}
GET /api/audit-logs?page_size=500&user=admin&action=login&start_time_ms=0
    -> {"total":41,"rows":41}
psql 对照: select count(*) from audit_logs; -> 354
坏参数 start_time_ms=abc -> HTTP 400  （400 = 客户端错误，不再是 500）
不存在的 user -> {"total":0,"rows":0}
分页 page=1&page_size=5 -> {"total":354,"rows":5}

# 坏参数是 400 而不是 500；空结果是 total=0 的正常形状
$ curl -s -o /dev/null -w 'start_time_ms=abc -> HTTP %{http_code}\n' 'http://127.0.0.1:8080/api/audit-logs?start_time_ms=abc'
start_time_ms=abc -> HTTP 400
